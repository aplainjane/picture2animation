# 大肥鱼：已确认动作示例

用户指定保留的蓝色角色案例，来源为阶段06第70版，已由用户确认。它包含最新手修素材、图层顺序、绑定、眼部六点与闭眼贴图，以及缩小收步摆臂后的四段动作。此示例是固定快照，之后原项目继续修改不会自动覆盖它。

## 示例文件

- [离线动作网页](../assets/examples/dafeiyu/index.html)：完整内嵌图片、最终素材覆盖和运行脚本。打开即可播放、逐段查看、慢放、拖动时间轴、显示骨骼和测试起停。页面没有审阅连接配置，不写回原项目，不提交确认。
- [动作数据](../assets/examples/dafeiyu/motion.json)：不含图片的参考JSON，保存原图尺寸、节点层级、静止坐标、部件绑定、完整动作轨道、效果轨道和实时过渡姿势。它是本示例的数据摘录，不是可直接提交检查点的角色设计，也不是Spine工程。
- [版本与文件摘要](../assets/examples/dafeiyu/example.json)：保存来源run、revision、设计摘要、真实确认状态及两个示例文件的SHA-256。来源确认仅说明该示例版本已确认，不能放行新角色。

不要为了解动作而把整个HTML载入模型上下文；先读本说明，按需用JSON工具提取片段、节点轨道和过渡值。美术效果在浏览器实际查看。

## 可参考的节奏

| 动作 | 时长 | 主要行为 |
| --- | --- | --- |
| idle | 4秒循环 | 温和呼吸、头胸轻动、头发与裙摆延迟摆动；眨眼独立于步频 |
| run | 0.5秒循环 | 双腿交替，左腿配右臂、右腿配左臂，躯干和重心随步伐起伏 |
| idle_to_run | 0.55秒 | 前35%下蹲蓄力，后65%回弹进入推进中的run相位 |
| run_to_idle | 0.85秒 | 前14%进入急刹姿势，保持至55%，随后回弹到推进中的idle相位 |

收步保留双臂向外展开，肩、肘相对原始静止方向的旋转幅度为最初大幅抬手版本的约1/3。不是将绝对角度或世界坐标直接除3；两侧骨骼原始方向不同。该幅度是本角色经过用户修订的选择，其他角色按其动作要求决定。

## 给后续AI的移植方式

1. 按需打开网页查看四段动作及实时起停；从 `motion.json` 提取 `production.clips/effects/transition_poses/transition_effects`。结合 `nodes` 的静止方向理解角度，不能只看正负号。
2. 以新角色有效的阶段05确认快照为输入，沿用其素材、坐标、绑定、六点及闭眼贴图。参考示例的时长、相位和缓动，按新角色的体型、左右语义及原始肢段方向重新计算轨道。非人形或结构不匹配时不要硬套此例。
3. 当前 `scripts/witch_motion.py` 已包含本例采用的编排、收步左右修正和1/3摆臂。可作为适配起点；其节点语义、靴子ID和可选附件约定须先核对。不要用该函数重建已有项目并覆盖人工成果。
4. 渲染和实时切换分别由 `assets/motion-review.html` 与 `assets/motion-runtime.js` 实现。同时保留独立片段与实时过渡定义，检查循环、切换任意相位、中途打断和最终目标相位；只复制关键帧不会自动复制实时衔接行为。
5. 对照实际画面检查交叉摆臂、双手向外的小幅收步、关节接缝和眼部效果。示例可作为视觉与行为参考，不能据此省略新角色的人工检查点。
